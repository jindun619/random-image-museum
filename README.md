# Random Image Museum

## Current Status

⚠️ **Note**: The site is currently unavailable due to exceeding Supabase's free tier limits. Efforts are being made to resolve this issue.

Random Image Museum is a web application built with **Next.js** and powered by **Supabase** for backend services. The project allows users to explore a collection of randomly displayed images on the main page. Users can sign up using their email address, log in, and upload their own images to contribute to the collection.

## 💡 Features

- **Random Image Display**: The main page showcases a random selection of uploaded images.
- **User Authentication**: Users can sign up and log in using their email address.
- **Image Upload**: Logged-in users can upload images to the platform.
- **Tech Stack**: Built with **Next.js** for the frontend and **Supabase** for backend services (authentication, database, and storage).
